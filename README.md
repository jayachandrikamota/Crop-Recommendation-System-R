# 🌱 Crop Recommendation System using Machine Learning
# Crop-Recommendation-System-R


## Project Overview

The Crop Recommendation System is a Machine Learning application designed to assist farmers and agricultural stakeholders in selecting the most suitable crop based on soil and environmental conditions. By analyzing critical agricultural parameters such as Nitrogen (N), Phosphorus (P), Potassium (K), temperature, humidity, pH, and rainfall, the system provides intelligent crop recommendations to support data-driven farming decisions.

The project implements a complete machine learning pipeline including data preprocessing, exploratory data analysis, feature engineering, model training, evaluation, and deployment. Multiple classification algorithms, including Decision Tree (Gini and Entropy) and Random Forest, are trained and compared to identify the most effective prediction model. An interactive Shiny application is integrated to allow users to input environmental conditions and obtain real-time crop recommendations.

This project demonstrates practical applications of data analytics, predictive modeling, agricultural informatics, and decision-support systems using the R programming language.
